# Sparse Ring Fiat–Shamir Challenge — Research Codec

`pqct/ring_challenge.py` turns a domain-separated transcript into the paper-shaped sparse challenge set `C_{w,p}` used by the experiment.

## Bound transcript

The seed includes:

- explicit domain label;
- statement bytes;
- `n`, `q`, and `k`;
- every commitment row and every canonical ring element;
- length framing for every variable-length component.

The output is generated by the existing rejection sampler and converted to a canonical ring element.

## Boundary

This closes only the transcript-to-challenge **encoding experiment**. It does not prove:

- Fiat–Shamir security in the quantum random-oracle model;
- uniformity beyond the implemented challenge sampler;
- special soundness of the full proof;
- statistical zero knowledge;
- suitability of the toy ring parameters.

The component is intentionally not wired into consensus, wallets, money, or a production verifier.
